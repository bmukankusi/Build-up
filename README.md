## Build up
- Unity project_game story. User moves around rooms to read a story of two girls, Emely and Anna.
- There are two scenes: 'MainMenu' and 'Game' scene.
- User can use arrow keys or WASD keys to move around.
- User clicks next to transition to a next room and next part of the story.
